# PCOM-DS-Minio-Ubuntu

NNP Data Store (DS) component. Pinned upstream image `minio/minio:RELEASE.2025-09-07T16-13-09Z` republished under the NNP namespace.

Published to Docker Hub on every push to `main`:

```
docker.io/nubonativesolution/pcom-ds-minio-ubuntu:RELEASE.2025-09-07-v1
docker.io/nubonativesolution/pcom-ds-minio-ubuntu:latest
```

Architecture: `linux/amd64`. CI/CD via the shared [PCOM-CICD](https://github.com/NNP-Platform-Components-PCOM/PCOM-CICD) reusable pipeline.
